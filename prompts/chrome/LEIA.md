# Rotinas para o Claude no navegador

Estas rotinas mexem em sites que não têm API aberta para o kit (TikTok Studio, comentários).
Duas formas de rodar:

- **Claude no Chrome (extensão):** salve o texto como atalho (/tiktok-agendar, /metricas-tiktok,
  /comentarios, /concorrentes) e, nas que forem semanais, crie uma tarefa agendada na própria extensão.
- **Tarefa agendada no app do Claude (computador ligado):** preferível quando a rotina precisa
  gravar arquivo na pasta do kit (métricas e ideias), porque ali o Claude usa o navegador e a pasta.

Regra que vale para todas: o Claude **lê e prepara**; quem publica, responde comentário ou clica no
botão final é você. Robô postando ou comentando é o jeito mais rápido de perder a conta.
